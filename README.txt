Pomodoro Timer

An app designed to work as a customizable timer, along with the Pomodoro method techniques, such as setting breaks, when they happen and for how long.

Right now it's at the very early stages of being made.

The goals is that the app will, beyond being 100% functional, include changing alarm sounds, a dark and light theme and system notifications.

Programmed in Python 3.x

A previous version of this project exist, but it suffers from being unoptimized and not fully functional.
